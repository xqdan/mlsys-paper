几乎所有合入 PR 都经 copybara-service[bot] 从 Google 内部仓库同步到 GitHub。合入日期由 PR 的 closed_at 转为 Asia/Shanghai 日期。下文按合入内容汇报，不逐一标注 bot 作者。琐碎清理、格式和文档微调已归并，只展开功能、性能、正确性、API/IR 与硬件后端上的重点。

1. IR：块缩放与稀疏矩阵乘

StableHLO #3032 / XLA #50340 / MHLO #50341 同步扩展 dot_general，为 NVFP4 / 块缩放 FP8 等低精度 GEMM 打下公共 IR 基础。

2. XLA GPU 后端

Triton RaggedDot 完成第 6/8 步；Blackwell 允许 NVFP4 block-16 scaled dot；cuDNN ragged-dot 增加能力探测与 dense 回退；Triton reduce-scatter / two-shot AllGather 继续增强。

3. Tokamax 内核库

routing MoE 接通块缩放 FP8；TPU 上新增面向 Qwen3-Next 等模型的 Gated Delta Net / KDA 内核，并支持上下文并行；同时修复多起 SM100 attention / ragged-dot 挂起、崩溃和错误结果。

4. Shardy 分区

为分片卷积补上 HALO exchange；并修复 ReshardToCollectives 中不能共存的 sub-axis 被错误切片、导致 replica group 错配、设备输出损坏的问题。

5. TorchTPU 注意力与编译

默认关掉 XLA HLO FlashAttention 改写，小形状推理优先走 StableHLO SDPA；扩展有界动态性，并发布 0.3.0 / 0.2.0 changelog。FSDP2 首次 backward 编译过慢、rounding 语义不一致仍在修。

6. XProf 安全与稳定性

独立 Web / gRPC 默认只绑 127.0.0.1，采集接口改为 POST 并拒绝跨域；修复 Linux aarch64 上 tcmalloc 错配释放导致的随机 abort。
