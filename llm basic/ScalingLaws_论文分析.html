1. 一句话结论

Transformer 语言模型的交叉熵，在不被另外两个因子卡住时，对非嵌入参数 N、数据量 D、最优分配后的训练算力 Cmin 各自服从幂律，趋势跨过六个数量级以上。形状（深宽比、头数、FFN 比）几乎无关。大模型显著更省样本。固定算力时，最优做法是把预算主要花在更大的模型上，数据只温和增加，并远早于收敛就停。

αN≈0.076
参数翻倍，损失约 ×0.95
N∝C0.73
算力涨 10×，最优模型约 ×5.5
D∝C0.27
同预算下 token 只约 ×1.8
+10%
算力最优停在收敛损失上方约 10%
这篇工作把“堆规模就变好”写成可外推的方程，直接塑造了 GPT-3 之后几年的训练配方。两年后 Chinchilla 证明：在他们的设定下，参数与 token 应近似等比增长，Kaplan 把过多预算给了模型、把模型训得太短。下面先按原文讲清他们测到了什么，再标出后来被改写的那一条。

2. 设定：N、D、C 怎么数

任务是自回归语言建模，指标是 1024 token 上下文上的平均交叉熵（nats）。数据是 WebText2：Reddit 外链 scrape，约 20.3M 文档、96 GB 文本、BPE 词表 50257，共 2.29×1010 token，其中 6.6×108 作测试。另在 Books、Common Crawl、Wikipedia、Internet Books 上测迁移。主模型是 decoder-only Transformer；对照 LSTM 与 Universal Transformer。优化器用 Adam（>1B 用 Adafactor），默认 2.5×105 步、batch 512×1024 token，3000 步线性升温后余弦衰减到 0。

符号含义这篇里怎么取
L交叉熵（nats/token）上下文内平均；有时按位置拆开
N模型规模不含词表与位置嵌入。标准形状下 N ≈ 12 nlayer dmodel²
D数据集 token 数22M–23B；过拟合实验用早停测试损失
C训练算力非嵌入：C ≈ 6NBS（前向约 2N、反向约 2×）。单位 PF-day = 8.64×1019 FLOP
Cmin最小算力若 batch ≪ 临界 batch，达到同一 L 所需算力
Smin最少更新步若 batch ≫ 临界 batch 时的步数

前向每 token 约 Cforward ≈ 2N + 2 nlayer nctx dmodel。当 dmodel ≫ nctx/12 时，注意力对上下文的二次项相对很小，所以训练算力里不把 nctx 项算进去。超长上下文时这条会偏。

不把嵌入算进 N 是这篇能画出干净幂律的关键。把嵌入算进去，深度会看起来像一个独立轴；去掉之后，不同深度塌到同一条 L(N) 上。少于 2 层或极端深宽比才会明显偏离。

3. 三条单因子幂律

当另外两个因子不构成瓶颈时，测试损失可以单独写成：

L(N) = (Nc / N)αN，αN ≈ 0.076，Nc ≈ 8.8×1013
L(D) = (Dc / D)αD，αD ≈ 0.095，Dc ≈ 5.4×1013
L(Cmin) = (Ccmin / Cmin)αCmin，αCmin ≈ 0.050，Ccmin ≈ 3.1×108 PF-days

覆盖范围大约是：Cmin 八个数量级、N 六个数量级、D 两个多数量级。上限未见拐弯，但损失必须在到达 0 之前变平——自然语言熵不为零。Nc、Dc 随词表和分词变，没有普适物理含义；指数才是“规模换多少损失”的量。

固定 batch 的经验 L(C) 也近似幂律（αC≈0.057），但外推该用按临界 batch 校正后的 Cmin。1 层到 2 层在约 10−5 PF-day 处有一个鼓包，拟合时丢掉 1 层网络。

4. 过拟合：N 与 D 必须一起涨

单独放大 N 或 D 会进入收益递减。他们把两条单因子律合成一个解析式，要求：(1) 改词表只整体缩放损失；(2) D→∞ 回到 L(N)，N→∞ 回到 L(D)；(3) 在 D=∞ 解析，从而有整数幂的 1/D 展开（过拟合应随数据方差 ~1/D）。于是 N 与 D 不对称：

L(N, D) = [ (Nc/N)αN/αD + Dc/D ]αD

联合拟合约 αN=0.076、αD=0.103、Nc=6.4×1013、Dc=1.8×1013（与单因子拟合略有差别）。过拟合程度 δL = L(N,D)/L(N,∞)−1 几乎只取决于比值 NαN/αD/D。要把过拟合压在随机种子涨落（约 0.02）以内：

D ≳ (5×103) N0.74

模型每放大 8×，数据大约只需 5×。22B token 的 WebText2 够训到约 109 参数而不明显过拟合；再大就会轻度过拟合。他们没有随 N、D 系统调 dropout（固定 10%）和数据增强，所以这条是“当前配方下的过拟合边界”，不是信息论极限。

最小的 22M token 子集（一轮大约 40 次更新）拟合很差，作者认为那是另一个小数据体制。

5. 学习曲线与临界 batch

沿用 McCandlish 等的大 batch 理论：存在临界 batch Bcrit。小于它，加大 batch 几乎不损失算力效率；超过它，回报递减。对任意固定损失 L，步数 S 与处理样本数 E=BS 满足

(S / Smin − 1)(E / Emin − 1) = 1，  Bcrit(L) ≡ Emin/Smin

在 B≈Bcrit 训练，大约用 2Smin 步、处理 2Emin 样本，是时间与算力的折中。实验上 Bcrit 不直接依赖模型大小，只依赖已达到的损失；梯度噪声尺度能大致预测它。损失每降约 13%，Bcrit 大约翻倍：

Bcrit(L) ≈ B* / L1/αB，B* ≈ 2×108 token，αB ≈ 0.21

最大模型收敛时，理想 batch 大约 1–2M token。因未知的最小损失 Lmin 远小于已达到的 L，他们把发散点放在 L→0。

无限数据、过完 warmup 之后，学习曲线可拟合为：

L(N, Smin) = (Nc/N)αN + (Sc / Smin)αS
αN≈0.077，αS≈0.76，Nc≈6.5×1013，Sc≈2.1×103

幂律在训练后期更准；早期瞬态对不上。αS 的普适性被解读为：损失后期近似二次时，Hessian 特征值密度大致不随模型大小变。数据有限时，早停步数有下界 Sstop ≳ Sc [L(N,D)−L(N,∞)]1/αS，真实会更晚，因为有限数据下测试损失降得更慢。

6. 算力怎么分：大模型、少步数

把 Smin = Cmin/(6N Bcrit) 代入 L(N,S)，对固定 C 求最优 N，得到

αCmin = 1 / (1/αS + 1/αB + 1/αN) ≈ 0.050–0.054
N ∝ CαCmin/αN ≈ C0.71–0.73，B ∝ C0.24，S ∝ C0.03，D = B·S

经验拟合：Nopt = 1.3×109 Cmin0.73，Smin 指数小到可能为 0。算力增加时，绝大部分应变成更大的 N；多出来的数据多半用来加大 batch（并行），串行步数几乎不涨。

算力最优停点

应停在收敛损失上方固定比例 αN/αS≈10%。不是“看起来已经平了”。

对比“训到快收敛”

若别人训到偏离 2%，算力最优配方用 2.7× 参数、7.7× 更少更新、65% 更少算力达到同一损失。

模型选错也不惨

0.6×–2.2× 最优规模只需大约多 20% 算力。大 2.2× 可少约 45% 步（更多并行），但极大型号上此式不可信。

硬件上人们常把小模型训得过长，因为模型并行难、数据并行易。作者因此强调：宽网络更好切分；流水线最终仍要加大 batch；稀疏/分支可换更多模型并行；训练中长模型或许能一直贴着算力前沿。

7. 自相矛盾与熵的猜想

算力最优下若不重复数据，D(Cmin) ∝ C0.26。但避免过拟合需要 D ∝ N0.74 ∝ C0.54。前者更慢，意味着即使每个 token 只用一次，最终仍会过拟合。数据瓶颈时 L ∝ D−0.095 变成 L ∝ C−0.03，会与 L ∝ C−0.050 相交。交点大约：

C* ∼ 104 PF-days，N* ∼ 1012，D* ∼ 1012 token，L* ∼ 1.7 nats/token

数值对指数极敏感，上下一个数量级都可能。最稳妥的读法：幂律必须在此之前失效。作者还猜想：这或许是 Transformer 从自然语言里能挖到的可靠信息上限，L* 粗估每 token 熵（WebText2 约 1.4 token/词、4.3 字符/token）。给每个上下文后接随机噪声只会整体抬高损失，交点位置（除绝对 L）不变。

8. 形状、LSTM、泛化

形状几乎不重要

固定非嵌入 N，扫深度、头数、dff/dmodel，损失只变几个百分点。深宽比差 40× 仍可接近 GPT-2 用的 (48, 1600)。(6, 4288) 相对其损失差距约 3%。作者援引 ResNet“深网是浅网集成”。

学习率也不敏感

只要总学习率够大、有 warmup、最后收到接近 0，余弦/线性/其他衰减差不多。种子涨落约 0.02–0.05。更大模型需要更小学习率；经验式 LR(N)≈0.003239−0.0001395 log(N)，在 N>1010 会坏掉。

LSTM 在上下文很早的 token 上能跟上 Transformer，后面的 token 跟不上；Transformer 优势来自长上下文。按位置 T 的损失本身也是幂律，更大模型不仅终点更好，对早期 token 也学得更快。短上下文 nctx=8 的中等模型，在最前面几个位置可以压过 nctx=1024 的最大模型。Universal Transformer 复用参数，同样 N 略好、同样 FLOP 略差。

只在 WebText2 上训练，其他语料上的损失几乎是训练分布损失加一个缓慢增长的常数偏移；与训练阶段、是否接近收敛、深度（固定 N）基本无关。12 层在 Internet Books 上过拟合是个孤立现象。

9. Caveat 与 Chinchilla 修正

作者自己列出的限制：没有任何一条幂律有坚实理论；Bcrit 外推不可靠；小数据与正则没扫完；算力估计忽略 nctx；未充分调初始化/动量；短训本可用更大学习率。幂律拟合比对数明显更好，但仍是经验曲线。

Chinchilla（Hoffmann 等，2022）改写了第 6 节的分配。Kaplan：Nopt∝C0.73、Dopt∝C0.27，口号是“大模型比大数据更重要”。Chinchilla：N 与 D 都应 ∝ C0.5，许多随后的大模型欠训。后来的调和指出：Kaplan 只计非嵌入参数、模型相对较小、学习率余弦收到 0（短训与长训不可比）、以及逐步数而非按 token 预算。今天做训练配方，应把这篇当“损失随规模光滑、形状次要、大模型更省样本”的证据，不要再按其 0.73/0.27 去分预算。

相关工作里，Hestness 等曾报数据随模型超线性增长，这里是次线性；EfficientNet 主张深度宽度不同指数，这里语言建模放大时应大致保持宽深比，且超参远不如总规模。他们没有看到过参数化“堵塞相变”。

10. 今天还该怎么用这篇

  • 报告规模时分开嵌入。词表项会搅乱 L(N)。比较架构先对齐非嵌入参数或非嵌入 FLOP。
  • 算力账用 C≈6N×token。这是至今默认的 Transformer 训练 FLOP 口算；超长上下文要把注意力项加回来。
  • 光滑外推仍可用，最优配比不能照抄。损失对 N/D/C 的单调幂律在更大尺度上大体还在；“固定算力该把模型堆多大、数据留多少”以 Chinchilla 及后续修正为准。
  • 样本效率随宽度/深度一起涨这一点没有被推翻：同样损失，更大模型用更少步、更少 token。这与推理侧“大模型一次算对”的直觉一致，但训练停点仍要按 token 预算重算。
  • 迁移 ≈ 训练损失 + 常数。换域先把源域交叉熵打下去，比在目标域上单独调深度更有效——至少在他们测过的英文网页/书/百科上如此。
  • 作者把这些关系比作理想气体定律：宏观量之间的经验约束，不管微观细节。下一步应是能推出指数的统计力学，以及确认损失下降是否对应任务能力的质变（“多即不同”）。
